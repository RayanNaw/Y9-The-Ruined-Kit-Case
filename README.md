# The Ruined Kit Investigation

Year 9 MYP Science, Unit 2: Body Systems. Students work through six stages: the mystery, discover, match, evidence, advice to Omar, and extend.

## Put it online with GitHub Pages
1. Sign in at github.com and create a new **public** repository, e.g. `Y9-The-Ruined-Kit-Case`.
2. Click **Add file > Upload files** and upload `index.html` (and this README).
3. Go to **Settings > Pages**. Under *Branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at https://rayannaw.github.io/Y9-The-Ruined-Kit-Case/.

Students do not need an account to open it. Answers are saved only in each student's own browser.
